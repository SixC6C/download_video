# Clip Saver – TikTok & Instagram Video Previewer & Downloader

A modern web application to preview and download TikTok and Instagram videos/reels in high quality MP4 format directly to your device.

## ✨ Features
- 🎬 **Video Preview Player**: Watch and inspect videos with player controls before downloading.
- ⚡ **0-Delay Download**: Instant download from pre-buffered cache.
- 📐 **Media Metadata**: Displays video resolution, duration, file size, and format chips.
- 📱 **Mobile & Desktop Responsive**: Clean dark mode UI with glassmorphism effects.
- 🚀 **Fast Processing**: Direct API extraction with fallback to `yt-dlp`.

## 🛠️ Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [Python](https://www.python.org/) (v3.9+) with `yt-dlp` installed:
  ```bash
  pip install -U yt-dlp
  ```

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SixC6C/download_video.git
   cd download_video
   ```

2. **Start the server**:
   ```bash
   npm start
   ```
   *(or `node server.js`)*

3. **Open in browser**:
   Navigate to `http://localhost:3000`

## ☁️ Deployment
Ready to deploy on [Railway.app](https://railway.app), [Render.com](https://render.com), or any Linux VPS using `npm start`.
